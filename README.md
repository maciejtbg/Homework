# Homework — zadania algorytmiczne (Java)

Zbiór rozwiązań zadań algorytmicznych i programistycznych w Javie, częściowo pokrytych testami jednostkowymi.

## Przykładowe zadania

- Struktury danych i algorytmy: `MaxSubArray`, `LongestSubstring`, `MinWindowSubstring`, `MedianFromList`
- Przetwarzanie tekstu: `Palindrome`, `ReverseString`, `LetterCount`, `JustifiedText`, `LengthEncoding`, `Brackets`
- Zadania symulacyjne/optymalizacyjne: `JobScheduler`, `MonteCarloCircle`, `ColorHouses`, `ElevationMap`

## Stack

Java, JUnit (testy w katalogu `test/`).
